7SAI: НЕ РАЗБУДИ СОСЕДЕЙ

Содержимое:
- index.html — интерфейс игры
- style.css — оформление и адаптивная мобильная версия
- game.js — игровой цикл, Canvas, соседи, события, Web Audio API, рекорды
- assets/track1.wav — загруженный трек «Fuck ’Em All»

Запуск: открой index.html в современном браузере. Если локальное аудио не запускается,
запусти сервер в этой папке командой: python -m http.server 8000
Затем открой http://localhost:8000

Управление:
- ИГРАТЬ — начать (первое нажатие также разрешает воспроизведение аудио)
- Play/Pause — музыка; |◀ / ▶| — переключение треков
- Ползунки — громкость и басы; ползунок под кнопками — позиция трека
- Space — Play/Pause музыки; Esc — пауза; ↑/↓ — громкость; B — прибавить басы
- ＋ ТРЕК 2 — выбрать второй аудиофайл с устройства во время игры

В исходном сообщении приложен только один аудиофайл. Поэтому track1.wav включён в архив.
Второй трек можно добавить через кнопку «＋ ТРЕК 2» во время игры.
Рекорд сохраняется в localStorage браузера.
